03红线是否真的被触发

数据层必须能在结构上阻止违规输出，而不是靠前端自觉。

Red Line 01 · 实证
多晶硅：三层数据一致地给出「零关税」
HTS 快照   2804.61.00.00   general = "Free"   rk = f
Chapter 99 附加措施命中      0 条
ADD/CVD 命中                 0 条
联邦公报   Proclamation 11052   Rule   生效 2026-09-22（早于发布 09-24）

数据层本身会输出一个看起来干净的「零关税」结论。 这不是 bug，而是 HTS rev.9 快照早于该公告所致。→ 页面必须让 L1 实时层与 L2 快照同屏对照， 否则「只出参考测算」这条红线在 UI 上根本落不了地。

Red Line 02 · 已结构化
税率形态码 rk 已写入每一行

Chapter 99 共 2,969 条，形态分布： 文本引用（不得换算）与可计算形态在数据层就已分开，前端按 rk == 't' 拒绝输出数字即可， 不需要在渲染时再猜字符串。

Red Line 03 · 覆盖率必须如实说明
ADD/CVD 只有 133 / 3,808 条文档能抽到 HS 码（3.5%）

原因是 Commerce / ITA 的公告大多不在摘要里列子目号， 只有 ITC 的调查公告会枚举 scope。→ 命中即高价值（都是正在办的大案）， 但未命中绝不等于没有措施。UI 必须写成「未检索到相关记录」， 不能写成「无反倾销措施」。3 年窗口共 319 个可命中编码。
